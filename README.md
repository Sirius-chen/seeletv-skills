# seeletv-skills

Reusable skills for screenplay-based creative development and visual asset production.

## Skills

- [seeletv-assets-trial](skills/seeletv-assets-trial/SKILL.md): Establish a screenplay’s creative direction and prepare consistent character and key prop reference assets.

Each skill includes a `SKILL.md` entrypoint and supporting references loaded only when needed.

## Installation

Copy `skills/seeletv-assets-trial` into your agent’s skills directory. For Codex, the default location is `~/.codex/skills/`.

## Usage

```text
Use $seeletv-assets-trial to establish the creative direction of my screenplay and prepare character and key prop assets.
```
