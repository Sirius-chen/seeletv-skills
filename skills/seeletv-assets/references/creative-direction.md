# Visual Direction and Look Development

## Derive a coherent direction

Start from the supplied script interpretation, intended emotional experience, medium, period, scale, and user preferences. Recommend one coherent direction. Offer alternatives only for a genuinely open choice; do not force a favorite film or a live-action pipeline onto the project.

A cinematic reference is useful when its borrowed dimension is explicit: source lighting, color relationships, material treatment, scale, or performance distance. Translate it into visible decisions. A precise film title is unnecessary when photographic or design language is clearer.

## Define the visible system

Specify enough to constrain assets:

- **Image language:** live action, animation, illustration, or another chosen treatment; relevant perspective and framing. Name camera or lens systems only when they help the actual target workflow. Distinguish capture medium from simulated finishing effects.
- **Lighting:** motivated source, direction, softness, contrast, highlight behavior, shadow detail, and skin treatment, or the chosen stylized equivalents.
- **Palette:** dominant/supporting relationships, temperature, saturation, meaningful accents, and intrinsic skin, costume, and prop colors. Exact values require an identified source or an explicit proposed swatch; do not present invented values as extracted evidence.
- **Materials and texture:** concrete surface behavior, wear, sharpness, grain/noise, atmosphere, and finish relevant to the story and medium.
- **Continuity:** what remains stable and which changes follow specific story states.

Write a reusable style paragraph, keeping additional explanation outside copyable prompts. Replace vague quality claims with visible properties; avoid conflicting capture systems and irrelevant equipment lists.

## Validate the look when useful

For a new visual direction, propose a representative frame that tests important interactions between character, environment, light, and materials. Use actual existing media when adequate. Generate a new test only when requested or covered by the user's production scope; a request for text direction alone does not authorize an image call.

Review the test against the intended tone, readable faces and objects, palette, and material behavior. A beautiful isolated portrait may not validate the environment or their interaction. Identify what was tested and what remains unknown. Do not turn one test into a mandatory set of boards.

## Separate final treatment from asset documentation

Neutral reference masters normally preserve intrinsic colors, shape, and material readability. Dramatic scene light must not silently redefine those colors. Carry the approved design language into masters while using documentation lighting appropriate to the purpose. A scene-specific mood frame may intentionally carry the final lighting; name that role explicitly.

Present consequential proposed choices for approval, reusing approvals already supplied. If later changes affect existing assets, identify only the dependent revisions needing review; do not restart unrelated work.
